# NIST SP 800-53 Rev 5

**Authoritative source.** NIST SP 800-53 Rev 5 (Security and Privacy Controls for Information Systems and Organizations), SP 800-53B Rev 5 (Control Baselines), and SP 800-53A Rev 5 (Assessment Procedures).

**Use this for**: FISMA, FedRAMP (which uses NIST 800-53 baselines), CMMC L2/L3 (uses 800-171 derived from 800-53), DoD IL5, internal NIST 800-53 attestations, any deliverable mapping NIST controls to cloud-native evidence.

## ID format

`AC-2`, `AC-2(3)` (enhancement 3 of AC-2), `SC-7`, `SC-7(5)`, `IA-5(1)`, etc.

## Baselines (drive which controls to include)

SP 800-53B Rev 5 defines four baselines:
- **Low** (~150 controls)
- **Moderate** (~280 controls)
- **High** (~410 controls)
- **Privacy** (overlay)

**Always ask the user which baseline.** FedRAMP Moderate, FedRAMP High, FedRAMP Low, FedRAMP Tailored Li-SaaS, and DoD IL2/4/5 each have their own derived baseline.

## Standard inherited citations (most CSPs)

Most physical and environmental controls (PE family) are inherited at the data center level. Pull the CSP's FedRAMP P-ATO + System Security Plan as inherited evidence:
- PE-2 — Physical access authorizations

- PE-15 — Water damage protection

## Build pattern for large frameworks

NIST 800-53 Moderate has ~280 controls + enhancements. NIST 800-53 High has ~410. Use the multi-file Python data + JSON intermediate pattern:

1. Split source data by control family (`nist_data_ac.py`, `nist_data_au.py`, etc.).
2. Merge into a single JSON intermediate.
3. Pass the merged JSON to the builder.

Use the SP 800-53A assessment procedures (Examine / Interview / Test) to drive the Evidence field.

## Typical extra_xlsx_tabs

Consider adding:
- `Control Selection / Tailoring` — list of controls with status (Selected / Inherited / Not Applicable / Tailored Out) and rationale.
- `Organization-Defined Parameters (ODPs)` — register of all ODPs with the entity's chosen values.

## NIST 800-53 evidence sourcing principles

- **SP 800-53A is the spec.** Each control has an SP 800-53A assessment procedure (Examine / Interview / Test) that names exactly what to test and what to look at. Use SP 800-53A as the source for the evidence field.
- **Organization-defined parameters.** Many controls contain ODPs (e.g., "[Assignment: organization-defined frequency]"). Document the entity's chosen ODP values in the description or in the dedicated ODP tab.
- **Inheritance via FedRAMP P-ATO.** For CSP-hosted systems, the CSP's FedRAMP package handles ~30-40% of controls. Document inheritance in the matrix.
- **Customer Responsibility Matrix (CRM).** Every FedRAMP-authorized CSP publishes a CRM. Use it to determine inheritance status for each control.

## Citation text source

NIST SP 800-53 Rev 5 (publicly available at csrc.nist.gov). Pull control statements and ODPs verbatim. SP 800-53A provides the assessment procedures.

## Typical evidence retention bullets

- Retain audit logs per AU-11 (organization-defined retention; typically 1 year online + 3 years archive for FedRAMP).
- Retain the SSP, SAR, POA&M, and ATO letter for the system authorization term.
- Retain annual assessments and continuous-monitoring evidence.
- For FedRAMP: monthly ConMon deliverables retained for the authorization term + 3 years.
